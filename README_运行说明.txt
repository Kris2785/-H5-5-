《凿通天山 · 筑福万民》互动游戏新闻修复版

运行方法：
1. 解压压缩包。
2. 进入 TianshanGameNews_Fixed 文件夹。
3. 双击 main.py，或在命令行执行：python main.py
4. 浏览器会自动打开本地页面。

本版已完成：
1. 已把你提供的图片统一放入 assets/img/ 并重命名为英文语义文件名，避免中文路径导致运行失败。
2. 通关页、海报页均显示真实勋章图片，而不是纯文字。
3. 第1关加入雪花风雪动画；第2关加入断裂带震动动画；第3关加入钻探动画；第4关加入 TBM 刀盘旋转动画；第5关加入通车庆祝和彩带动画。
4. 第3关、第4关、第5关改成工程模拟式交互，不再只是简单答题。
5. 音效用 WebAudio 代码合成，不依赖外部音频文件，避免缺少 mp3 导致运行失败。

主要文件：
- main.py：Python 本地服务器启动文件
- index.html：页面入口
- styles.css：界面、动画、移动端布局
- game.js：5关游戏逻辑、勋章、海报、新闻总结
- assets/img/：所有已重命名图片素材
